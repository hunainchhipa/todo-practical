# To-Do List Application

This is a fully functional to-do list application built as part of a practical interview task. The app allows users to manage their tasks efficiently by adding, marks as complete or incomplete, and deleting tasks.

## Live Demo: [To-Do List App](https://todo-practical.netlify.app/)

## Features

- Add tasks to your to-do list.
- Mark tasks as complete or incomplete.
- Delete tasks when they are no longer needed.

## How to Run Locally

Follow these steps to run the project on your machine:

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/hunainchhipa/todo-practical.git
   cd todo-practical

   ```

2. **Install Dependencies:**

   ```bash
   npm install

   ```

3. **Start the Development Server:**
   ```bash
   npm run dev
   ```

## Technologies Used

- Frontend: React.js
- Styling: CSS
